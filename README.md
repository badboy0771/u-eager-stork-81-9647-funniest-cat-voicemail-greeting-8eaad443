An entry for the [Funniest Cat Voicemail Greeting](https://make.fun/c/u-eager-stork-81-9647-funniest-cat-voicemail-greeting-8eaad443) competition on [make.fun](https://make.fun): one voicemail greeting, recorded by a cat, at most 120 characters.

## The entry

> Hi, it's Miso. I'm napping in the box you threw away. Leave a message after the beep — I'll knock it off the shelf.

115 characters. Miso is unbothered, a little menacing, and already planning her next crime while you listen: napping in the box you threw away, then knocking the phone off the shelf right after the beep.

## How it works

`main.ts` writes the greeting to `/output/entry.txt` and validates it first against the competition gate: 1–120 characters, not only whitespace, a single line. Run it with Node 22+:

```sh
node main.ts
```

The same text is also kept in `entry.txt` for reference.
